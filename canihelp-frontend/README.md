# CanIHelp - Frontend React com Vite

Um projeto frontend React criado com Vite, pronto para desenvolvimento rápido.

## Tecnologias

- **React 19** - Biblioteca de componentes
- **Vite** - Build tool e dev server
- **JSX** - Sintaxe de componentes
- **CSS** - Estilização moderna com.gradientes

## Começando

### Instalar dependências

```bash
npm install
```

### Desenvolvimento

```bash
npm run dev
```

Acesse em http://localhost:5173

### Build

```bash
npm run build
```

### Preview do build

```bash
npm run preview
```

## Estrutura do projeto

```
canihelp-frontend/

│   └── ...
```

## Scripts disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Compila para produção
- `npm run preview` - Visualiza o build localmente
- `npm test` - Executa os testes
